## Self-Guided Learning

This virtual course is designed to support **self-guided learning**, allowing participants to work through materials at their own pace.

### Daily Materials
- **Presentation Slides** for each day can be found in the repository folder:  
  [`virtual_course_modules_2025`](https://github.com/WCSCourses/CRISPR_informatics_2025/tree/main/Virtual_Course_Run/virtual_course_modules_2025) <br />

 Please find the [Course Timetable here](https://github.com/WCSCourses/CRISPR_informatics_2025/blob/main/Virtual_Course_Run/WCS_CRISPR_Virtual_Timetable2025.pdf) <br />

### Course Data and Practicals
- All datasets and hands-on practicals are available in:  
  [`virtual_course_data_2025`](https://github.com/WCSCourses/CRISPR_informatics_2025/tree/main/Virtual_Course_Run/virtual_course_data_2025)

### Software Requirements
- Detailed software requirements and setup instructions are available in the Informatics Guide:  
  [Informatics Guide – CRISPR Virtual Course Run](https://github.com/WCSCourses/CRISPR_informatics_2025/tree/main/Virtual_Course_Run)

You are encouraged to explore the materials freely, revisit content as needed, and make full use of the practicals provided to reinforce your understanding.
